# 운행노트 0.1.0 (7) 테스트 안내

- 앱을 실행하고 강제 종료 후 다시 열어 정상 시작하는지 확인해 주세요.
- 흰색·차콜 바탕과 파란 포인트가 홈·기록·미터기·설정에 적용됩니다. 상태 표시줄과 제목, 하단 메뉴와 안전 영역이 자연스럽게 연결되는지 확인해 주세요.
- 휴대폰에서 미터기를 시작하면 실시간 현황에 거리·경과 시간과 진행 상태만 표시됩니다. 요금은 휴대폰 미터기와 영수증에서 확인합니다.
- CarPlay의 소형 실시간 현황에서도 요금 없이 거리와 경과 시간이 보이는지 확인해 주세요. 시간은 분 단위로 표시됩니다.
- 일시정지·재개·종료 시 표시가 맞는지, 기존 운행 기록이 유지되는지 확인해 주세요.
- 실제 차량에서 조작은 정차 후 진행해 주세요.

## 검증 범위

TypeScript, JS 70개, config plugin 4개 테스트 통과. 이전 로컬 Release에서 밝은 홈·어두운 미터기·고정 종료 버튼과 잠금 화면 실시간 현황을 확인했다. 최종 CarPlay 활성화 아카이브의 실행 및 실차 검증 결과와 구분한다. 이번 문서는 업로드용 안내 초안이며 TestFlight 게시를 의미하지 않는다.
