# GPS 속도 측정

## 빌드 2 변경

실기기에서 걷는 중 40→10km/h가 반복되는 제보를 받아, 좌표 간 거리만으로 속도를 산출하던 방식을 변경했다.

- 기기가 제공하는 `coords.speed`(m/s)를 우선 사용한다. 유효한 0은 정지이며 음수·null·비정상 범위는 속도 없음이다.
- 최근 네이티브 속도 3개의 중앙값으로 단발성 급변을 줄이고, 화면 숫자만 실제 샘플 간격에 따른 완만한 평활화를 적용한다. 요금의 저속 판정에는 화면 평활화 값을 쓰지 않는다.
- 0.5m/s 이하는 정지로 처리한다. 정지 시 화면은 즉시 0이 되고 좌표 흔들림은 거리에 더하지 않는다.
- 네이티브 속도가 없을 때는 최근 3~5초 좌표 구간으로 보조 계산한다. 정확도 반경에 비해 이동이 작으면 속도를 미확정으로 표시하며 저속 시간 요금은 더하지 않는다.
- 거리 누적은 두 좌표의 정확도 반경을 고려한 이동 문턱을 넘었을 때 한다. 매번 정확도 반경을 거리에서 빼지는 않는다.
- 4초 이상 오래된 위치는 사용하지 않는다. 중복·역순 위치는 신뢰 상태를 초기화하지 않고 무시한다.
- 짧은 샘플 간격의 위치 흔들림은 거리에서 제외하되 유효한 네이티브 속도는 유지한다. 큰 위치 점프는 계속 거절한다.
- `BestForNavigation` 정확도를 요청한다. iOS의 콜백 간격은 1초로 보장되지 않아 위치 timestamp 차이를 사용한다.

타입 검사 및 전체 테스트 56개 통과. 걷기(좌표상 40→10km/h, 네이티브 약 5km/h), 정지 흔들림, 초기 이동, 불규칙 간격, 단발 속도 급변, 속도 부재, 오래된 위치, 순간이동을 회귀 검증했다.

실기기 재검증은 아직 필요하다. Expo가 iOS `speedAccuracy`를 노출하지 않으므로 네이티브 속도의 오차를 직접 검증할 수 없고, 불량 GPS 환경에서는 측정이 누락되거나 실제 거리보다 적게 집계될 수 있다. 독립 CarPlay 앱 및 백그라운드 GPS는 이 수정 범위에 포함되지 않는다.

근거: [Expo Location](https://docs.expo.dev/versions/latest/sdk/location/), [Apple CLLocation.speed](https://developer.apple.com/documentation/corelocation/cllocation/speed).
