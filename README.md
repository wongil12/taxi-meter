# 택시 놀이

React Native + TypeScript로 만든 GPS 기반 오락용 택시 미터의 초기 버전입니다. 실제 운임 계산이나 결제용이 아닙니다.

## 실행

Node.js 22.13 이상을 권장합니다.

```sh
npm ci
npm start
```

Expo SDK 57과 호환되는 Expo Go에서 QR 코드를 열어 테스트합니다. GPS는 실제 휴대폰에서 확인하세요. 시뮬레이터는 위치 시나리오를 공급해야 이동이 측정됩니다. 개발 빌드가 필요하면 `npx expo run:ios` 또는 `npx expo run:android`를 사용합니다. 이 명령은 네이티브 프로젝트를 생성하며 Xcode 또는 Android 개발 환경이 필요합니다.

## 구현 범위

- 위치 권한 요청, GPS 이동 거리·속도·측정 시간 표시
- 시작, 일시정지, 재개, 종료, 새 주행
- 기본 요금과 거리/저속 시간 계산을 분리한 순수 TypeScript 엔진
- 부정확한 좌표·오래된 좌표·위치 급변·작은 흔들림 필터
- 앱이 백그라운드로 이동하면 일시정지, 사용자가 다시 시작
- 기기 테마에 따른 밝은/어두운 기본 화면
- 위치를 서버에 전송하지 않으며 주행 데이터는 메모리에만 유지

놀이 규칙: 기본 1.6 km 4,800원. 기본거리 이후 15 km/h 초과에서는 131 m마다 100원, 이하에서는 30초마다 100원. 같은 구간의 거리·시간 요금을 중복 부과하지 않습니다. 기본거리 이내 대기는 무료입니다. 공식 지역별 요금표가 아닙니다.

## 검증

```sh
npm run typecheck
npm test
npx expo export --platform ios --platform android
```

계산·GPS 단위 테스트 13개 및 두 플랫폼 JavaScript 번들 생성을 확인했습니다. 네이티브 빌드, 실기기 GPS, 권한 팝업과 시각 검증은 아직 완료하지 않았습니다.

실기기 확인: 처음 권한 허용/거부/설정 복구, 위치 서비스 꺼짐, 정지 상태의 GPS 흔들림, 실제 이동, 신호 끊김, 일시정지/재개, 화면 잠금·앱 전환, 종료 후 재시작을 확인합니다. 설정에서 큰 글자와 밝은/어두운 테마도 확인합니다.

GPS 좌표만으로 거리와 속도를 추정하므로 저속 이동, 터널, 실내에서는 오차가 있습니다. 신뢰할 수 없는 구간은 재기준점을 잡고 제외합니다. 측정 시간은 신뢰할 수 있는 GPS 샘플 사이의 시간이며 벽시계상 전체 주행 시간과 다를 수 있습니다. 앱 종료 시 기록은 사라집니다.

## CarPlay

**현재 미구현**입니다. 독립 CarPlay 앱은 Apple entitlement 승인이 필요합니다. iOS 26 Live Activity로 차량 화면에 정보를 표시하는 경로도 검토했습니다. [지원 검토 및 통합 순서](docs/CARPLAY.md)를 참조하세요. Expo Go만으로 CarPlay/ActivityKit 네이티브 기능을 검증할 수 없습니다.

## 구조

- `App.tsx`: 기본 화면
- `src/hooks/useTaxiMeter.ts`: 위치 권한·구독·앱 수명 주기
- `src/domain/meter.ts`: 상태와 요금 계산
- `src/location/tracking.ts`: 좌표 필터 및 거리 계산

서브에이전트는 계산 엔진, GPS 처리, CarPlay 조사를 분담했습니다. 디자인 방향은 사용자 선택 전의 기본 화면입니다.

## 의존성 확인

2026-10-07 설치한 공식 Expo 템플릿의 의존성에서 npm audit 22건(높음 15, 보통 7)이 보고됐습니다. Expo/Metro 등 간접 의존성 경로가 포함되며, 일부 권고가 구버전 Expo로의 파괴적 변경을 제시해 강제 적용하지 않았습니다. 배포 전에 지원 버전의 수정 여부를 재확인해야 합니다.
