# 차량 운행 기록

React Native + TypeScript로 만든 차량 운행 기록 관리 앱입니다. 거리·시간을 기록하고 월별 저장 기록을 조회합니다. 택시 미터기는 선택형 부가 기능으로 제공합니다.

## 실행

Node.js 22.13 이상을 권장합니다.

```sh
npm ci
npm start
```

Expo SDK 57과 호환되는 Expo Go에서 QR 코드를 열어 테스트합니다. GPS는 실제 휴대폰에서 확인하세요. 시뮬레이터는 위치 시나리오를 공급해야 이동이 측정됩니다. 개발 빌드가 필요하면 `npx expo run:ios` 또는 `npx expo run:android`를 사용합니다. 이 명령은 네이티브 프로젝트를 생성하며 Xcode 또는 Android 개발 환경이 필요합니다.

## 구현 범위

- 위치 권한 요청, GPS 이동 거리·속도·측정 시간 표시
- 시작, 일시정지, 재개, 종료, 새 주행
- 운행/기록/미터기/설정 하단 탭, 홈 월별 요약과 최근 기록
- 일반 운행(log)은 무과금, 택시(taxi) 선택 주행만 요금 계산
- 전체/운행 기록/택시 기록 필터와 일반 운행 상세 공유
- 주행/일시정지 중 탭 바 위에 조작 버튼 고정
- 시작 성공 시 준비 화면에서 주행 화면으로 전환하고 자동차 출발 애니메이션 표시
- 주행 중 도로 애니메이션, 일시정지·종료 시 정지, 기기의 동작 줄이기 설정 존중
- 기본 요금과 거리/저속 시간 계산을 분리한 순수 TypeScript 엔진
- 부정확한 좌표·오래된 좌표·위치 급변·작은 흔들림 필터
- 앱이 백그라운드로 이동하면 일시정지, 사용자가 다시 시작
- 기기 테마에 따른 밝은/어두운 기본 화면
- 완료한 주행을 휴대폰에 최근 100건 저장하고 개별 삭제
- 히스토리 및 완료 화면에서 영수증 이미지/텍스트를 시스템 공유 창으로 공유
- 위치 좌표는 서버 전송/히스토리 저장하지 않으며 기록에는 일시·거리·시간·요금만 보관
- iOS 26+ Live Activity와 CarPlay Dashboard 표시 코드 연동

택시 미터기 선택 시 요금 기준: 기본 1.6 km 4,800원. 기본거리 이후 모든 이동 거리 131 m마다 100원, 15 km/h 이하에서는 30초마다 100원을 추가합니다. 저속 이동 구간에는 거리·시간 요금을 함께 계산합니다. 기본거리 이내 대기는 무료입니다. 공식 지역별 요금표가 아닙니다.

## 검증

```sh
npm run typecheck
npm test
npx expo export --platform ios --platform android
```

계산·GPS·주행 시계·저장소·CarPlay 상태 테스트 67개 및 두 플랫폼 JavaScript 번들 생성을 확인했습니다. iOS 26.5 / iPhone 17 Pro 시뮬레이터에서 네이티브 빌드, 위치 권한, 주행 종료/저장, 재실행 후 히스토리 유지, 영수증 PNG 첨부 공유 창, 잠금 화면 Live Activity 및 하단 고정 주행 조작 버튼을 확인했습니다. 실제 기기 GPS와 실제 차량 CarPlay Dashboard는 미검증입니다.

실기기 확인: 처음 권한 허용/거부/설정 복구, 위치 서비스 꺼짐, 정지 상태의 GPS 흔들림, 실제 이동, 신호 끊김, 일시정지/재개, 화면 잠금·앱 전환, 종료 후 재시작을 확인합니다. 설정에서 큰 글자와 밝은/어두운 테마도 확인합니다.

GPS 위치와 기기가 제공하는 속도로 측정하므로 저속 이동, 터널, 실내에서는 오차가 있습니다. 신뢰할 수 없는 구간은 재기준점을 잡고 제외합니다. 측정 시간은 GPS 수신과 독립적으로 매초 갱신되는 주행 경과 시간입니다. 일시정지와 백그라운드 시간은 제외하며, GPS가 끊겨도 주행 상태라면 시간은 흐릅니다. 요금 계산은 신뢰할 수 있는 GPS 구간만 사용합니다. 새 네이티브 iOS 런타임은 진행 중인 주행을 최근 체크포인트에서 일시정지 상태로 복원합니다. Android와 기존 배포본에는 이 복원 기능이 없습니다. 완료한 주행은 저장 성공 후 앱을 재실행해도 남습니다. 저장 실패 시 재시도 또는 영수증 공유가 가능합니다.

설정에서 영수증 하단의 운수 이름 키워드를 1~12자로 저장할 수 있습니다. 기본값은 우리운수이며, 변경한 이름은 기존 기록을 포함한 이미지·텍스트 영수증에 적용됩니다. 이름은 이 기기에 저장됩니다.

## CarPlay

iOS 26 이상의 **Live Activity 표시 방식**으로 코드 연동했습니다. 주행 중 요금과 상태를 CarPlay Dashboard·잠금 화면·Dynamic Island에 표시합니다. Expo Go에서는 비활성화되며 `npm run ios`로 네이티브 빌드가 필요합니다. 휴대폰을 잠그면 현재 GPS 정책에 따라 측정을 멈추고 일시정지를 표시합니다. 차량에서 시작·일시정지·종료하는 독립 CarPlay 앱과 공통 네이티브 미터 코드를 추가했습니다. 기본 배포 설정에서는 비활성화되며 Apple 권한 승인 후 별도 빌드가 필요합니다. 연결 중 잠금 상태 측정과 실제 차량 동작은 아직 검증하지 않았습니다. [빌드 설정과 검증 범위](docs/CARPLAY.md)를 참조하세요.

## 구조

- `App.tsx`: 기본 화면
- `src/hooks/useTaxiMeter.ts`: 위치 권한·구독·앱 수명 주기
- `src/domain/meter.ts`: 상태와 요금 계산
- `src/location/tracking.ts`: 좌표 필터 및 거리 계산

서브에이전트는 계산 엔진, GPS 처리, 기록 형식, 저장소 및 CarPlay 연동을 분담했습니다. 디자인 방향은 사용자 선택 전의 기본 화면입니다.

## 의존성 확인

2026-10-07 설치한 공식 Expo 템플릿의 의존성에서 npm audit 24건(높음 16, 보통 8)이 보고됐습니다. Expo/Metro 등 간접 의존성 경로가 포함되며, 일부 권고가 구버전 Expo로의 파괴적 변경을 제시해 강제 적용하지 않았습니다. 배포 전에 지원 버전의 수정 여부를 재확인해야 합니다.

## 운행 기록 개편 검증 (2026-10-09)

TypeScript 테스트 67개, 네이티브 계산 검사 67개와 iOS simulator 빌드를 통과했다. iPhone 17 Pro에서 홈 → 일반 운행 시작 → 종료 → 요금 없는 상세, 택시 미터기 시작 시 기본 요금, 기록 목록 종류 구분을 화면으로 확인했다. 기존 두 기록도 보존됐다. 실제 도로 GPS·CarPlay 연결 검증 및 이 변경의 TestFlight 배포는 미완료다. 기존 앱 ID·설치 이름·아이콘은 보존했으며 공개 스토어 브랜딩은 아직 바꾸지 않았다.
